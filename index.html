一句寫在書邊的註記，
數學家追了 358 年

費馬最後定理講的其實是一句很「小學」的話：把一個立方數拆成兩個立方數相加，做不到；四次方，做不到；五次方、六次方、以至於任何三次以上，全部都做不到。 問題是 —— 為甚麼？又憑甚麼肯定？

xn+yn=zn n ≥ 3 · 無正整數解

1637 年之前無人能證，1995 年之後無需再證

「將一個立方數分成兩個立方數之和、一個四次方數分成兩個四次方數之和，或者一般地將任何高於二次的冪分成兩個同次冪之和，都是不可能的。我確實發現了一個非常美妙的證明，但這裡的頁邊太窄，寫不下。」

01

一句話講完：它到底在講甚麼

先把命題講到連小學生都聽得明

找三個正整數 x、y、z，令到

xn + yn = zn
x, y, z 為正整數 · n 為整數且 n ≥ 3

費馬最後定理說的是：這樣的解，一組都不存在。

n = 2：有很多解

3² + 4² = 5²，5² + 12² = 13²，8² + 15² = 17²……這就是人人中學都見過的「畢氏三元組」，而且有無限多組。

n ≥ 3：一組都沒有

3³ + 4³ = 91，不是任何整數的立方；試盡所有數字都一樣。由三次方開始，方程突然「斷絕」了所有正整數解。

所以定理不是說「這條方程無解」—— n = 2 時它明明有無限多解。它說的是：由三次方開始，整整一整個無限家族，全部無解。這種「一刀切」的乾淨，正是它嚇人的地方。

為甚麼只需檢查質數指數？

假設 n 可以分解成 n = m · p（p 為質數）。那麼

xn + yn = (xm)p + (ym)p
即：若指數 n 有解，則指數 p 亦有解

反過來講，只要證明指數為質數 p 時無解，所有 p 的倍數就自動無解。再加上 n = 4 這個特例（任何 ≥ 3 的整數，要麼被 4 整除，要麼有一個奇質因數），整個無限的問題就縮減成「所有奇質數 + 4」—— 一個仍然無限、但結構清晰得多的清單。

02

故事的開頭：一位法官的頁邊筆記

1637 年 · 圖盧茲

皮埃爾·德·費馬（Pierre de Fermat, 1601–1665）正職是法國圖盧茲地方法院的法官，數學是他的「副業」。他有一個習慣：讀書時把想法直接寫在書的空白處，而且幾乎從不寫下證明過程。他會寫「我證明了」，然後就沒有然後。

1637 年，他在古希臘數學家丟番圖《算術》的一本拉丁文譯本頁邊，讀到關於畢氏定理的討論，於是寫下了那段著名的話。他當時應該沒有想過，這幾行字會變成數學史上最貴的一句「寫唔落」。

費馬 1665 年去世。他的兒子克萊門特－薩繆爾整理了父親的註記，1670 年出版了帶註解的《算術》版本，這段頁邊話才公開於世。此後三百多年，它一直被叫做「費馬最後定理」—— 之所以叫「最後」，是因為它是費馬遺留下來、最後一個未被解決的猜想。

一個有趣的細節：費馬其實證明了 n = 4 的情況（用「無限下降法」，而且證明是完整留下的）。所以他自己至少知道，這條路的第一步該怎樣走。但他那句「絕妙證明」從來沒有人找到，也沒有任何 17 世紀的數學工具足以支撐它。

03

啱定錯？答案是：啱，而且已經證實

它不再是「猜想」，而是「定理」

已證
成立

這是真的命題，不是未解之謎

1994 年 9 月，英國數學家安德魯·懷爾斯（Andrew Wiles）與理查德·泰勒（Richard Taylor）補上了證明的最後一道缺口；1995 年 5 月，論文正式刊於《數學年刊》（Annals of Mathematics）第 141 卷。自此，它是一條定理，不是猜想。

三件要分清楚的事

第一，「定理」這個詞有門檻。數學裡，猜想（conjecture）是「相信但未證」，定理（theorem）是「已嚴格證明並經同行審查」。1994 年之前，大家習慣叫它 Fermat's Last Theorem，其實是歷史慣性 —— 當時它技術上仍是猜想。1995 年之後，這個名字才真正名副其實。

第二，「電腦試過冇反例」不等於證明。電腦可以窮舉到極大的數字範圍，而事實上也真的有人做過，全部都找不到反例。但整數有無限多個，有限次的檢驗，永遠無法覆蓋無限。這就是為甚麼需要一個真正的證明，而不是更快的電腦。

第三，費馬本人那個「絕妙證明」，幾乎肯定不存在。理由很直接：n = 3 的情況連歐拉（Euler）都要小心處理，他當年的證明還被後人發現有漏洞；n = 4 要用無限下降法；而現代證明動用了 20 世紀的模形式、伽羅瓦表示、代數幾何。很難想像 17 世紀的頁邊可以塞得下這些。更可能的解釋是：費馬證明了某個他以為等價、但其實不等價的東西。

「啱」的前提要講清楚：定理講的是正整數。如果放寬到實數，1³ + 2³ = 9 = (∛9)³，解當然要多少有多少。數學命題的真假，永遠相對於它的假設。

索菲·熱爾曼（Sophie Germain）取得突破：若 p 為質數且 x、y、z 全部不被 p 整除，則無解。這是第一個「一整類指數」的結果。

1847

日本數學家谷山豐與志村五郎提出猜想：所有橢圓曲線都對應某個模形式。當時無人預料，這條猜想會成為終結費馬問題的鑰匙。

里貝特（Ken Ribet）嚴格證明弗雷的直覺：那條曲線確實不可能是模形式。於是「證明谷山－志村猜想」就等於「證明費馬最後定理」。

懷爾斯在劍橋牛頓研究所連續三天演講，最後一刻宣佈證明完成。全球頭條。

審稿過程中發現致命漏洞：關鍵的「歐拉系統」上界推導不成立。證明暫時崩塌。

懷爾斯與學生泰勒找到出路，用後來被稱為 Taylor–Wiles 系統 的方法繞過漏洞。9 月 19 日，他寫下「I think I've got it」。

05

證明是怎麼做的？

先講骨架，再講三個層次

先說一句老實話：完整的證明不可能在一個網頁裡講完。懷爾斯的論文本身 109 頁，預設讀者已掌握模形式、伽羅瓦表示、代數幾何。但證明的骨架其實相當漂亮，而且可以用日常語言講清楚 —— 以下就是那副骨架。至於可以逐句寫完的部分，我們放在下一節 06 · 完整證明，並在那一節標明哪幾格是引用已發表的定理。

整個策略可以濃縮成一句：不直接解方程，而是證明「如果它有解，就會逼出一件根本不可能存在的東西」。

第一層：把無限的問題縮小

如上一節所述，只需處理奇質數指數與 n = 4。這一步在 17 至 19 世紀就完成了，但它把「所有 n ≥ 3」變成「所有質數 p ≥ 3」，讓後人可以逐個擊破。

第二層：古典方法（17–19 世紀）

這一層的關鍵詞是唯一分解。整數有一個我們習以為常的性質：每個數分解成質數乘積的方式是唯一的。19 世紀的數學家試圖把這個性質搬到更大的數系（例如 ℤ[√−3]、ℤ[ζp]）裡使用，結果發現它不一定成立。

  • 歐拉（n = 3）：在 ℤ[√−3] 上分解，但該環並非唯一分解環，證明存在缺口。
  • 熱爾曼：繞開這個問題，先處理 x、y、z 與 p 互質的情況。
  • 庫默：乾脆發明「理想數」來修復唯一分解，證明所有正則質數成立。這是代數數論的起點之一。

但庫默的方法有極限：非正則質數（irregular primes，例如 37、59、67）處理不了。這條路走到 20 世紀中，已經非常吃力 —— 逐個質數補，永遠補不完。

第三層：現代路線（1985–1995）

真正的突破不在數論，而在幾何。弗雷的洞見是：把方程的解「翻譯」成一條曲線。

1

假設有解，造一條曲線

若有 ap + bp = cp（p ≥ 5 為質數），弗雷考慮橢圓曲線 E：y² = x(x − ap)(x + bp)。這條曲線的判別式是 16(abc)2p，結構異常「整齊」。

它「太乾淨」，乾淨到不可能是模形式

塞爾（Serre）預測、里貝特（1986）證明：這條曲線對應的伽羅瓦表示可以一層層「降級」，最終降到 level 2。但 level 2 的模形式只有零，不存在。結論：E 不可能是模形式。

但所有半穩定曲線都是模形式

這正是懷爾斯證明的東西 —— 谷山－志村－韋伊猜想的一個重要特例。於是 E 既要「不是模形式」，又要「是模形式」。

▼
4

矛盾 → 假設不成立 → 定理成立

所以 ap + bp = cp 無正整數解。證畢。

用一個比喻：假設費馬方程有解，就等於造出了一個「有身份證號碼、但戶籍資料庫裡完全查不到這個人」的公民。第 3 步證明「所有公民都一定在資料庫裡」，於是矛盾。

技術上，懷爾斯要處理的是伽羅瓦表示的變形環與 Hecke 代數之間的關係。他原本以為可以用「歐拉系統」直接比較兩者的尺寸，但那個上界推導在 1993 年被發現不成立。最終的修補方案（Taylor–Wiles 系統）非常巧妙：不去硬碰那個上界，而是把問題搬到一個輔助的質數集合上，用計數論證反過來逼出等式。這個方法後來成為整個 Langlands 計劃的核心工具之一，影響力遠超費馬定理本身。

那有沒有「更簡單」的證明？

至今沒有已知的初等證明。每年都有業餘愛好者寄來「三頁證明」，但都過不了審查。這不代表未來不可能，但可以肯定的說：任何可行的證明，都必須處理「唯一分解失效」這個深層障礙 —— 而這正是現代代數數論存在的理由。

另一個有趣的側面：如果 abc 猜想（至今仍未證明）成立，一般認為可以推出費馬最後定理對足夠大的指數成立。這說明費馬問題並不是一座孤島，而是整個數論結構的一個投影。

第 0 步：先砍掉九成九的指數

定理講的是「所有 n ≥ 3」，但其實只要證兩個家族。這一步在 17 世紀就完成了，而且完全初等。

引理 0.1（只需看質數與 4）

若存在 n ≥ 3 與正整數 x、y、z 使 xn + yn = zn，則存在奇質數 p 或 n = 4 的同類解。

證明

拿任何一個 n ≥ 3。分兩種情形。

有奇質因數。寫 n = pm，其中 p 為奇質數。令 X = xm、Y = ym、Z = zm，則

Xp + Yp = (xm)p + (ym)p = xn + yn = zn = Zp，

所以指數 p 也有解。

沒有奇質因數。那麼 n = 2k。因為 n ≥ 3 而 2 的次方只有 1、2、4、8…，所以 k ≥ 2，n 是 4 的倍數：n = 4j。令 X = xj 等，同理得 X⁴ + Y⁴ = Z⁴。∎

反方向是廢話：如果質數 p 有解，那麼 p 的倍數統統有解。所以「所有 n ≥ 3 無解」等價於「所有奇質數 p 無解，而且 n = 4 無解」。

引理 0.2（可以假設互質，並取最小的一組）

若有解 xn + yn = zn，令 d = gcd(x, y)。則 d 整除 z，而且除以 dn 之後仍然是一組解。故可假設 gcd(x, y) = 1。

證明

因 dn 整除 xn 與 yn，故 dn 整除 zn，於是 d 整除 z。把等式兩邊同除 dn 得 (x/d)n + (y/d)n = (z/d)n，仍是一組解。若 d > 1，z 就變小了；無限次除下去不可能，所以總有一次會停 —— 停在 gcd = 1 為止。∎

這條「取最小的一組」正是下一步無限下降法用來撞牆的東西：最小性。

第 1 步：n = 4，完整寫一次無限下降法

費馬本人留下來的證明就是這一個。它的漂亮之處是：不用任何 19 世紀以後的工具，只需要「畢氏三元組的公式」加「一個很小的算術觀察」。

x4 + y4 = z2
我們證更強的版本：右邊是平方就夠，不必是四次方

為甚麼證更強反而更容易？因為 z⁴ 本身就是一個平方 (z²)²，所以平方版無解 ⇒ 四次方版無解。而平方版多了一個好用的工具：畢氏三元組。

引理 1.1（本原畢氏三元組）

設 a、b、c 為正整數，a² + b² = c²，gcd(a, b) = 1，且 a 為奇、b 為偶。則存在正整數 m > n，gcd(m, n) = 1，m 與 n 一奇一偶，使

a = m² − n²，　b = 2mn，　c = m² + n²。

證明

由 a² = c² − b² 得 b² = (c − a)(c + a)。

兩個因子都是偶數。因為 a 奇、b 偶 ⇒ c² = a² + b² 是奇 + 偶 = 奇，所以 c 奇；奇 ± 奇 = 偶。✓

令 r = (c + a)/2，s = (c − a)/2，兩個都是正整數，而且

rs = (c + a)(c − a)/4 = b²/4 = (b/2)²。

gcd(r, s) = 1。任何公因數 g 整除 r + s = c 與 r − s = a，所以 g 整除 gcd(a, c)。而本原三元組必有 gcd(a, c) = 1（否則 a、c 的公因數也整除 b² = c² − a²，違反 gcd(a, b) = 1）。故 g = 1。

兩個互質數的乘積是平方 ⇒ 各自是平方。把 r、s 質因數分解：每個質數只會出現在其中一邊，而它在乘積裡的次數是偶數，所以在自己那一邊也是偶數。故 r = m²，s = n²，其中 m > n ≥ 1。

代回去：a = r − s = m² − n²，c = r + s = m² + n²，b = 2mn。m、n 一奇一偶（否則 m² − n² 為偶，與 a 奇矛盾），互質則來自 gcd(r, s) = 1。∎

引理 1.2（兩個很小的算術事實）

(i) 若 x 為奇數，則 x² ≡ 1 (mod 4)，且 x⁴ ≡ 1 (mod 16)。

(ii) 平方數除以 16 的餘數只可能是 0、1、4、9。特別地，x⁴ + y⁴（x、y 皆奇）≡ 1 + 1 = 2 (mod 16)，不可能是平方。

證明

(i) 奇數寫成 2k + 1，平方得 4k(k + 1) + 1，而 k(k + 1) 必為偶，所以 ≡ 1 (mod 8)；再平方，1² 在 mod 16 下仍是 1（嚴格講：≡ 1 (mod 8) 的數平方 ≡ 1 (mod 16)）。

(ii) 偶數 = 2t，平方 = 4t² ≡ 0 或 4 (mod 16)；奇數平方 ≡ 1 或 9 (mod 16)（逐個試 1、3、5、7 即可）。兩奇數的四次方之和 ≡ 2，而 2 不在 {0, 1, 4, 9} 之中。∎

工具齊了。以下是主證明，六步。

  1. 假設有解，並取 z 最小的一組。由引理 0.2，可設 gcd(x, y) = 1。由於平方版的無解性會遺傳給更小的 z，最小性就是我們最後要撞的那堵牆。
  2. x、y 不可同為奇數。否則由引理 1.2(ii)，z² ≡ 2 (mod 16)，但平方數不可能 ≡ 2。所以一奇一偶；交換 x、y 不影響方程，故設 x 奇、y 偶。
  3. 對 (x², y², z) 用引理 1.1。這是一個本原畢氏三元組（(x²)² + (y²)² = z²），奇的一邊是 x²。於是有 m > n，gcd(m, n) = 1，一奇一偶，使
    x² = m² − n²，　y² = 2mn，　z = m² + n²。
  4. 把 y² = 2mn 拆開。m、n 互質。對任何奇質數 q，它在 y² 裡的次數是偶數，而它只落在 m 或 n 其中一邊，所以在那一邊也是偶數次。至於質數 2：若 m 為偶，則 1 + (2 在 m 中的次數) 是偶數，故該次數為奇，於是 m/2 是完全平方。結論只有兩個可能：
    情況一：m = 2s²，n = t²
    情況二：m = t²，n = 2s²
  5. 情況一直接矛盾。代入 x² = m² − n² 得
    x² + t⁴ = 4s⁴ = (2s²)²。
    左邊：x 奇 ⇒ x² ≡ 1 (mod 4)；m 偶 ⇒ n = t² 奇 ⇒ t 奇 ⇒ t⁴ ≡ 1 (mod 4)。所以左邊 ≡ 2 (mod 4)，右邊 ≡ 0 (mod 4)。不可能。
  6. 情況二產生一個更小的解，違反最小性。代入得 x² = t⁴ − 4s⁴，即
    x² + (2s²)² = (t²)²。
    這又是本原畢氏三元組（若質數 q 同時整除 x 與 2s² = n，則由 x² + n² = m² 得 q | m，與 gcd(m, n) = 1 矛盾）。奇的一邊是 x，偶的一邊是 2s²，再用一次引理 1.1：
    2s² = 2uv，即 s² = uv；　x = u² − v²；　t² = u² + v²，
    而 gcd(u, v) = 1。兩個互質數之積 uv 是平方 ⇒ u = r²，v = w²。於是
    r⁴ + w⁴ = t²。
    這是同一條方程的一組新解，而它的「z」是 t，比原本的 z = m² + n² = t⁴ + 4s⁴ 小（因為 t ≥ 1 時 t⁴ + 4s⁴ > t）。這違反了第 1 步「z 最小」的選擇。

兩種情況都不可能，假設不成立。故 x⁴ + y⁴ = z² 無正整數解，n = 4 的費馬方程因而無解。證畢

這一步為甚麼叫「下降」：我們沒有直接撞出矛盾，而是用一組解造出更小的一組解。如果每組解都能造出更小的，就會有無窮無盡往下掉的正整數 —— 但正整數不能無限下降。所以一開始那組解不可能存在。這個手法費馬叫它 descente infinie，是後來三百年裡所有 n 的證明的共同語言。

第 2 步：n = 3，一個乾淨的模 9，加一個不乾淨的下降

這一格是整條古典路線的試金石。200 年來所有「三頁證明」都在這裡滑倒，原因很具體：它需要進入一個新的數系。

情況 (a)：三數都不是 3 的倍數 —— 三行證完

先注意任何整數的立方除以 9，只可能是 0、1、8：

1³ = 1，2³ = 8，3³ = 0，4³ = 64 ≡ 1，5³ ≡ 8，6³ ≡ 0，7³ ≡ 1，8³ ≡ 8　(mod 9)

而且 n³ ≡ ±1 (mod 9) 正好對應「n 不是 3 的倍數」。所以若 x、y、z 全部不被 3 整除，則

x³ + y³ ∈ {1 + 1, 1 − 1, −1 − 1} ≡ {2, 0, 7}　(mod 9)，

而 z³ ∈ {1, 8}。兩個集合沒有交集 —— 矛盾。∎

剩下的只有「3 整除 x、y、z 其中之一」這個情況。要處理它，歐拉把方程搬進一個新的數系。

新數系：ℤ[ω]

令 ω 為三次單位根（ω³ = 1，ω ≠ 1），即 ω = (−1 + √−3)/2，滿足 ω² + ω + 1 = 0。考慮

ℤ[ω] = { a + bω ： a, b 為整數 }，

定義「大小」（範數）N(a + bω) = a² − ab + b²。它有個關鍵性質：N(αβ) = N(α)N(β)。

為甚麼要搬進來？因為在 ℤ 裡 x³ + y³ 只拆得開一半，而在 ℤ[ω] 裡它會裂成三個：

x3 + y3 = (x + y)(x + ωy)(x + ω2y)
三個因子相乘等於 z³；若它們「互質」，每個就只能是立方

引理 2.1（ℤ[ω] 是唯一分解環）

ℤ[ω] 裡的每個非零元素，分解成「質元素」乘積的方式唯一（差一個單位 ±1, ±ω, ±ω²）。

為甚麼（幾何版，一句話講完）

把 ℤ[ω] 畫在複數平面上，它是一個正三角形格子（不是正方形格子）。任何一點到最近格點的距離最多 1/√3 < 1，所以「帶餘除法」做得成：被除數 = 商 × 除數 + 餘數，而餘數的範數嚴格小於除數的範數。有帶餘除法 ⇒ 歐幾里得環 ⇒ 唯一分解。這也是歐拉當年漏掉的一步：他假設了唯一分解，但 ℤ[√−3] 並不具備它；換成 ℤ[ω] 才成立，補完的人是勒讓德與高斯。關鍵補丁

引理 2.2（互質乘積是立方 ⇒ 各自是立方）

設 α、β 在 ℤ[ω] 中互質（沒有共同的質元素），且 αβ 是某元素的立方。則 α、β 各自等於「一個單位乘以一個立方」。

證明

由引理 2.1，把 α、β 各自分解成質元素。因為兩者互質，每個質元素只出現在一邊；而它在乘積 αβ 裡的指數是 3 的倍數，所以在自己那一邊也是 3 的倍數。把指數三個一組收起來，就是立方。剩下沒收的是單位。∎

於是 x + ωy 應該是「單位 × 立方」。把那個單位記作 ε（ε ∈ {±1, ±ω, ±ω²}）：

x + ωy = ε(u + vω)³。

先取 ε = 1。其餘的 ε 只是把整個平面旋轉 120° 或 240°（乘以 ω 就是旋轉），係數比較照樣成立，只差一個符號 —— 下面不妨就用 ε = ±1 來看。

右邊老實展開（用 ω² = −1 − ω、ω³ = 1）：

(u + vω)3 = (u3 − 3uv2 + v3) + (3u2v − 3uv2)ω
ω 的係數 = 3uv(u − v)：三個整數的乘積，被 3 整除

比較 ω 的係數，得到 y = ±3uv(u − v)。比較實部，得到 x = ±(u³ − 3uv² + v³)。這兩個式子加上原本的 z³ = x³ + y³，就能反過來把 (x, y, z) 換成一組更小的解 —— 又是下降，撞的又是「z 最小」那堵牆。

誠實標記：這一格還沒寫完

上面每個零件都可驗證，缺的是把「比較係數」接到「造出更小的解」之間那兩三頁代數：要小心三個因子其實可能共用 1 − ω（範數為 3 的那個質元素），要處理符號與單位，然後把新解的三個數逐一證明比舊的小。這是勒讓德 1825 年補完的部分，完整版見 Edwards《Fermat's Last Theorem》第 2 章。

換句話說：n = 3 的證明骨架是完整的，代數留了一個明確的洞，而且我們知道洞在哪、由誰補的。這跟「三頁證明」的差別在於：它不會假裝洞不存在。

第 3 步：p ≥ 5，懷爾斯的那一格

古典方法在非正則質數前停住（庫默能處理「正則」的，37 就不行）。現代路線乾脆不碰 p 的算術，改為把假設翻譯成幾何物件。

兩邊相撞

「是模的」（第 5 步）與「只可能來自 level 2，而 level 2 是空的」（第 3、4 步）互相矛盾。所以假設不成立，ap + bp = cp 無解。證畢。

為甚麼第 4 步這麼致命：level 2 是「最省資料」的等級 —— 只允許 2 這一個質數的分歧。弗雷曲線的判別式偏偏乾淨到所有其他質數的資訊都被 p 次方「吸收」掉，於是它除了 2 之外沒有東西可講。而 level 2 的模形式數量是 0：連一個可以拿來對應的對象都沒有。

把三格串起來，整條證明的邏輯就是：假設有解 ⇒ 造出一條「必須存在」又「不可能存在」的曲線。這跟直接解方程完全是兩種工作方式 —— 也是為甚麼它用了 358 年。

八行速查

  1. 只需證 n = 4 與奇質數 p（引理 0.1），並可假設 gcd(x, y) = 1（引理 0.2）。
  2. n = 4：無限下降法，用畢氏三元組公式把解變小，撞「z 最小」。全證。
  3. n = 3：3∤xyz 用 mod 9 三行解決；3 | xyz 進 ℤ[ω]，三個因子各為立方，比較係數後下降。
  4. p ≥ 5：假設有解，造弗雷曲線 y² = x(x − ap)(x + bp)，判別式 16(abc)2p，半穩定。
  5. 里貝特：它的表示必須降到 level 2。
  6. 虧格公式：dim S₂(Γ₀(2)) = 0，所以 level 2 的東西不存在。
  7. 懷爾斯–泰勒：半穩定曲線一定模 ⇒ 它必須存在。
  8. 矛盾 ⇒ 無解 ⇒ 定理成立。

順手幫你識破「三頁證明」

下次再有人寄來一份短證明，問三個問題就夠：

  • 「n = 3、3 整除其中一數」怎麼處理？這是最多假證明滑倒的地方 —— 它逼你用 ℤ[ω] 的唯一分解，或者別的等價機器。
  • 有沒有處理非正則質數？如果作者用庫默的辦法，問他 37 怎麼辦。
  • 「所有 p」是怎麼一次過關掉的？逐個質數驗證永遠驗不完；要嘛有模性定理，要嘛有別的整體性論證。

最後一句老實話：這一節把「可以完整寫出來的部分」寫完了，也把「必須引用哪兩條定理」指名道姓地標了出來。第 4、5 步的內部（變形環、Hecke 代數、Taylor–Wiles 系統）仍然是 109 頁的硬工作，本文沒有假裝重寫它 —— 這正是「完整證明」與「假裝完整」的分界線。

幾個常見誤解

順手拆掉幾個流傳很廣的說法

既然 n ≥ 3 無解，為甚麼 n = 2 又有解？

因為二次方對應的是「面積」，而三次以上對應的結構完全另一個層次。具體地說，n = 2 時方程對應圓上的有理點，而圓上可以用參數化造出無限多個有理點 —— 這就是畢氏三元組公式：

(m² − k², 2mk, m² + k²)

取 m = 2、k = 1 得 (3, 4, 5)；取 m = 3、k = 2 得 (5, 12, 13)。但這套參數化只對二次曲線（虧格 0）有效；由三次方開始，曲線的虧格 ≥ 1，有理點的結構完全改變 —— 這正是費馬問題困難的幾何根源。

會不會其實有反例，只是數字太大找不到？

不會。這不是「未找到」，而是「已證明不存在」。1995 年的證明是演繹性的：它不依賴任何數值檢驗，而是從邏輯上排除所有可能。任何反例都會同時推翻模性定理 —— 而模性定理已被獨立驗證、廣泛應用。

費馬那個「絕妙證明」是不是失傳了？

幾乎肯定不是失傳，而是根本不存在（或者證明的對象不是我們以為的東西）。理由：n = 3 已需要代數數論的技巧，n = 4 要用無限下降法，而一般情形需要 20 世紀的模形式理論。17 世紀的數學語言裡，沒有可以承載這個證明的結構。

數學史家的共識比較接近：費馬很可能證明了某個他以為等價的命題，或者只在某些特例上成立。

為甚麼 n = 4 要另外處理？不是已經包含在「所有指數」裡嗎？

因為 4 不是質數，但它也不是任何奇質數的倍數 —— 它是 2 的冪。所以「只需檢查質數」這一步漏掉了它，必須單獨證明。費馬本人用無限下降法證明了 x⁴ + y⁴ = z⁴ 無解，這是整條路上最早被攻克的一塊。

證明了這個，有甚麼實際用途？

費馬最後定理本身沒有直接應用 —— 你不會用它來設計橋樑或加密資料。但它催生的工具極其重要：代數數論、理想數、模形式、伽羅瓦表示、模性提升（modularity lifting）。

今天你手機裡的橢圓曲線密碼學（ECC），用的正是同一套橢圓曲線理論 —— 注意，這不是說「因為費馬定理所以有 ECC」，而是兩者站在同一個數學分支上。基礎研究的回報，通常以這種「意外的鄰居」形式出現。

現在還有甚麼未解決的相關問題？

很多。例如 abc 猜想（被視為數論中最深的三個問題之一）、BSD 猜想、以及 Langlands 計劃的大部分內容，都仍然開放。懷爾斯當年發展的模性提升技術，如今是這些問題的主要武器之一。

換句話說：費馬問題被解決了，但它打開的門，多數還沒走完。
